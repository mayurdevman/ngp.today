# NGP Today website

A minimal, monochrome dark Jekyll site designed for free GitHub Pages hosting. It reads approved, published records from `_data/events.json`, generated by the Python ingestion package. Search and date filters run in the browser.

## Current limitations

- The data file is intentionally empty until real event sources are approved and events are reviewed.
- The connector accepts organizer-approved HTTPS iCalendar feeds only. It does not scrape ticketing platforms.
- Ingested events remain pending; a moderation/publishing workflow is still required before real events can appear.
- Community submissions and calendar subscription feeds are not implemented yet.
- `ngp.today` is the proposed custom domain, not yet verified as available, registered, or connected. GitHub Pages will first provide a free `github.io` URL after the project is pushed to GitHub and Pages is enabled.

## Local preview

The site can be built with Jekyll from this directory. The GitHub Actions workflow builds and deploys it to GitHub Pages on pushes to `main`, manual runs, and scheduled refreshes. Add only approved URLs to the `NAGPUR_ICS_FEEDS` GitHub Actions secret.
